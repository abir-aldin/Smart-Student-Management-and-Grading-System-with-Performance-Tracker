# Student Performance Management System

A C++ based Student Performance Management System developed using Object-Oriented Programming (OOP) concepts. The system helps manage student information, department records, subject marks, CGPA calculation, performance evaluation, and topper identification.

## Overview

This project is a console-based application designed to manage academic performance data efficiently. It demonstrates the practical implementation of OOP principles such as classes, inheritance, and structured data management in C++.

## Features

- Add and manage departments
- Add students under specific departments
- Store student information including name, age, and ID
- Enter subject-wise marks
- Calculate CGPA based on average marks
- Display student performance status
- Provide improvement suggestions based on marks
- Find department topper
- Find subject-wise topper

## Technologies Used

- C++
- Object-Oriented Programming (OOP)
- Standard Template Library (STL)
- Console Application Development

## OOP Concepts Implemented

- Classes and Objects
- Inheritance
- Encapsulation
- Data Organization using Structures and Classes
